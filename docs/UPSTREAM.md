# Source notes

On Record imports code from [Hydra-Of-Malice/hack-october-who-said-what-brain](https://github.com/Hydra-Of-Malice/hack-october-who-said-what-brain), starting at commit [`69b2d11c1662f38110f35a2d8f4896345f075a1e`](https://github.com/Hydra-Of-Malice/hack-october-who-said-what-brain/commit/69b2d11c1662f38110f35a2d8f4896345f075a1e).

The original project and its contributors retain credit for that implementation. Its Apache 2.0 license is included in this repository. On Record adds the source in separate feature branches, with integration changes recorded in each PR.

The initial changes set the display name to On Record, keep demo seeding off in the example environment, and adapt the setup documentation to the files available here. Internal package names and environment variables retain the `wsw` names used by the source.

The source documents Claude Code assistance. Codex assists this repository's staged import, integration checks, and documentation. Test results and performance figures reported by the source are not new measurements from On Record.

The graph-schema branch imports `graph/cypher.py` and `graph/text.py` unchanged from that snapshot. Its package initializer exposes only the modules present here. The Compose file includes the source's database service, with ports bound to localhost; the application service comes later. The schema checks adapt the source's index assertions and add direct full-text/vector retrieval checks so they can run before `GraphStore` is imported.

The text-embeddings branch imports the `HashEmbedder` portion of `brain/embed.py` from the same pinned snapshot. It adds explicit positive-integer dimension validation to match the graph store's contract, and exposes only the available embedder through `brain/__init__.py`. Its tests check normalisation, basic lexical ranking, empty input, and dimension validation.

The model-embeddings branch adds the `GemmaEmbedder` adapter and cached `get_embedder()` provider factory from the pinned snapshot. It validates constructor options before loading the model, downloads plain files under `WSW_MODELS_DIR`, and retries missing external weights once, keeping the ONNX graph and its weights together instead of resolving them through separate cache symlinks. The tests use new synthetic ONNX fixtures and the real CPU runtime and tokenizer, and cover configured provider selection, partial-download recovery, and fallback when model loading fails; no trained weights are committed.

The hybrid-retrieval branch imports `brain/retrieve.py` from the same pinned snapshot, combining text, vector, speaker, and recency sources with reciprocal-rank fusion. Integration changes validate rank limits and isolate query-embedding failures so text and graph searches remain available. Compatibility checks accept equivalent passages when vector neighbors tie and treat a missing self-match as inconclusive. Recency follows the graph store's sequence order even when timestamps tie. New tests exercise ranking and the real local graph store, including meeting scope, speaker-name refresh, and cached checks for incompatible vectors. The package exposes only the retrieval and embedding modules present here; assistant and HTTP wiring come later.

The local-llm branch adapts the Ollama text-chat implementation and shared message helpers from `brain/llm.py` in the pinned snapshot. It provides direct text/tool calls with bounded HTTP timeouts, a narrowly triggered retry for unsupported thinking options, and a cached provider factory for local or deterministic fake execution. Integration changes validate constructor settings, response shapes, provider selection, and invalid tool arguments through `LLMError`. Audio and hosted providers remain separate imports. Transport and factory tests exercise real HTTP request construction and offline routing without making inference or performance claims about a live model.

The gemini-llm branch adds the hosted Gemini text adapter from the same pinned source snapshot. It translates the shared message contract into Google GenAI contents, supports JSON mode and function declarations, validates candidate and tool-call response shapes, retries once in compatibility mode for rejected advanced options, and selects Gemini automatically when a key is configured. Tests use an injected client stub and synthetic GenAI responses; they do not call the hosted service or claim live model quality.

The openai-llm branch adds the OpenAI-compatible text adapter from the same pinned source snapshot. It targets `/v1/chat/completions`, maps the shared tool exchange with stable call IDs, validates response and argument shapes, and exposes explicit provider selection through the existing settings. HTTP transport tests use `MockTransport`; no hosted endpoint is contacted.

The model-concurrency branch adds process-wide endpoint gates for the text adapters. The bounded scheduler limits in-flight generations, caps ordinary waiting callers, times out abandoned queues, and lets explicitly marked priority work pass ordinary questions. Unit tests cover capacity, priority, overflow, timeout, and endpoint-key reuse without making model requests.
